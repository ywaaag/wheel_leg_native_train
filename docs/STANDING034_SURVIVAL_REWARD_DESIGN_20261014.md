## 奖励公式：单位为分/秒

所有量取post-physics/pre-reset真实状态。有效mask M要求合法初始化后学生控制、有限状态、无runtime fault、无当前物理跌倒/机身违规支撑；沿用当前物理安全条件，不把严格高度/镜像/速度证书加入M。

软支撑因子：

`B = clamp(min(F_L,F_R)/2N,0,1) * clamp((root_height-.20m)/.10m,0,1)`。

F为现有轮sensor合力norm，仅支撑proxy，不声称法向力；无接触或低位不发完整站立收益。root高度不是COM。0.20～0.30m渐进门控是此草案的新选择，不是修改现有安全阈值。

高度质量改为`G_h=1/(1+((h-.34)/.04)²)`；有界几何成本`C(x)=x²/(1+x²)`。本次v14核心实现将高度也改为有理函数，以减少远场Gaussian快速衰减；0.04m尺度和收益权重不变。初版草案Gaussian核算保留为历史算术，不能当作当前公式。

水平速度质量与姿态质量改为有非零尾部的有理函数：

```
Q_v = 1 / (1 + (vx²+vy²)/0.30² + (yaw/0.30)²)
Q_p = 1 / (1 + (pitch/0.15)² + (roll/0.15)²)
```

速度为native机体前向/横向，单位m/s；yaw为rad/s。用水平速度模长平方，不遗漏横向滑动。两质量均正负对称、平滑、有界；远场灵敏度仍减小，不能保证摆脱局部最优，也不是势能差分。0.30只是reward尺度，不自动成为验收阈值。

| 分项 | 密度公式 | 最大收益/成本 | 说明 |
|---|---|---:|---|
| 少量持续支撑存活 | +1 B | +1 | 从原草案+4降为+1，不要求严格姿态入口 |
| **低速直立联合保持** | **+5 B Q_v Q_p** | **+5** | 主要收益必须同时低速、回正；非二值门控 |
| 高度 | +1.5 B Q_v G_h | +1.5 | 高速状态不能独立领满高度收益 |
| 零速辅助 | +1 B Q_v | +1 | 即使歪斜，也有减速改善方向 |
| 实际关节镜像 | -.20 mean(C([qLhip+qRhip,qLactive-qRactive]/.10)) | -.20 | 不强制动作相等 |
| 实际轮心对齐 | -.30 C(relu(abs(offset)-.01)/.03) | -.30 | 1cm deadband，实际水平投影差 |
| 实际腿长平衡 | -.15 C((lL-lR)/.02) | -.15 | hip-anchor至轮心长度，不由关节角替代 |
| 角速度 | -.10 mean(C([omega_pitch,omega_roll]/1rad/s)) | -.10 | 阻尼偏好，不替代姿态角质量 |
| 实际施加力矩努力 | -.02 mean((tau/[40,40,5.5,40,40,5.5])²) | 限矩内约-.02 | 不额外惩罚短时触限 |
| 实际执行目标变化 | -.002 mean(C(delta_target/[.1,.1,10,.1,.1,10])) | -.002 | left-first六通道，腿rad、轮rad/s |

总步reward：`r_t = M * .01 * (上述密度之和)`。entry/success/failure事件奖励均0；不增加大额成功事件或额外跌倒惩罚。真正终止步仍按真实pre-reset状态；若已触发物理失败，M=0，之后不得领生存收益。正常期限到达是timeout，不是跌倒。

必须整套替换原分项，不重复叠加旧v13高度、support、零速Huber、镜像项。无total clip、连续dt恰一次。最高密度仍8.5/秒，但高速状态只能领约1/秒基础收益，不能独立拿满高度和直立收益。

负项上界合计.772/秒：完整有效支撑B=1且applied torque确在声明限矩内时，最低净密度至少.228/秒，即使姿态/速度较差，也不会仅因这些辅助成本让结束episode更划算。该下界不适用于失触、低位或超出实际限矩的异常状态；异常力矩必须核验，不偷偷clip读回值。

这不是数学上的词典序目标：长时间滚动仍可能比短时间完美姿态获得更多回报。独立评估/选模必须把“持续低速直立时间”与“纯生存时间”分开，不能只按alive排序。
